# Simple Room Chat App

Simple Room Chat App is a real-time room-based chat application that allows users to create chat rooms, invite friends, and communicate instantly. The application uses WebSockets to provide real-time messaging between users.

This project was built to explore real-time communication and gain practical experience working with WebSockets in a full-stack application.

## About

Simple Room Chat App enables users to create private chat rooms and share room codes with friends. Once inside a room, participants can exchange messages in real time.

To keep the application lightweight, chat history is automatically removed when all members leave a room.

---

## Features

* Create chat rooms
* Join rooms using a room code
* Chat with friends in real time
* Instant messaging powered by WebSockets
* Automatic room cleanup when all users leave
* Responsive user interface

## How It Works

1. Create a chat room.
2. Share the room code with friends.
3. Friends join the room using the code.
4. Chat instantly in real time.
5. When all members leave, the room and its messages are automatically deleted.
